## ملاحظة عن ملفات PDF القديمة
`docs/01_welcome_screen.pdf` و`02_grade_selection_screen.pdf` و`03_home_screen.pdf` شرح سطري **للنسخة الأولى** من الشاشات الثلاث (قبل قاعدة البيانات والراوتر). الكود تغيّر بعدها (الشاشة الرئيسية خصوصًا أُعيدت كتابتها بالكامل)، فالمرجع المحدَّث هو ملفات `.md` هنا. يمكن إعادة توليد PDF لأي شاشة عند الحاجة.
