## ملفات PDF
- **شرح بحسب الموضوع:** `pdf/` — نسخة PDF من ملفات `.md` هذه.
- **شرح سطرًا بسطر لكل كود `lib/`:** `docs/line_by_line/` — 16 ملفًا (الأساس، قاعدة البيانات، منطق الملفات، المكوّنات المشتركة، الكتالوج، ثم كل شاشة، وآخرها حسابي ورمز الطالب وإعدادات حسابي، والسلاسة وحذف الملف). كل مقطع كود يتبعه «ماذا يفعل؟» و«لماذا بهذه الطريقة؟»، والتغطية كاملة: كل سطر غير فارغ في كل ملف `.dart` (غير المولَّد) مشروح.
- **قديمة:** `docs/01_welcome_screen.pdf` و`02_grade_selection_screen.pdf` و`03_home_screen.pdf` شرح سطري **للنسخة الأولى** من الشاشات الثلاث (قبل قاعدة البيانات والراوتر). حلّت محلّها ملفات `docs/line_by_line/`.
