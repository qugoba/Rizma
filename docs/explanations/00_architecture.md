# 00 — بنية التطبيق وترابط الطبقات

## الغرض
رِزمة تطبيق تعلّم **يعمل دون إنترنت أولًا**. كل ما يراه الطالب يأتي من جهازه: ملفه، تقدّمه، ومحتوى الدروس. هذا الملف يشرح كيف تترابط أجزاء الكود حتى يعرف أي عضو في الفريق أين يضع الكود الجديد.

## الخريطة العامة

```
lib/
  main.dart                 يشغّل التطبيق داخل ProviderScope
  app/
    rizma_app.dart          MaterialApp.router + العربية RTL + الثيم
    router.dart             كل المسارات (go_router)
    routes.dart             أسماء المسارات (ثوابت) — منفصلة كي لا تعتمد الشاشات على الراوتر
  core/                     كل ما تشترك فيه أكثر من ميزة
    db/                     قاعدة البيانات (Drift): جداول + DAOs
    theme/                  الألوان والأنماط والثيم
    widgets/                مكوّنات مشتركة (زر، شريط تقدّم، شريط سفلي…)
    utils/                  دوال صرفة بلا واجهة (رمز الطالب، تجزئة الرمز السري…)
    strings/ar.dart         كل النصوص الظاهرة للمستخدم
  features/                 ميزة = مجلد (شاشات + مزوّدات + مستودع)
    welcome/ grade_selection/ home/ profiles/ catalog/ ...
assets/
  content/catalog_grade5.json   هيكل المحتوى (مواد ← وحدات ← دروس ← مفاهيم)
  fonts/Cairo-*.ttf             الخط داخل التطبيق (يعمل دون إنترنت)
  icons/ images/                أصول SVG من Figma
```

## الطبقات واتجاه الاعتماد
الاعتماد يسير **من الأعلى إلى الأسفل فقط**:

```
الشاشة (Widget)
   │ تقرأ وتنادي
   ▼
المزوّد (Riverpod Provider / Notifier)
   │ يستخدم
   ▼
المستودع (Repository)  ← يضع قواعد العمل (التحقق، القفل، توليد الرمز…)
   │ يستخدم
   ▼
DAO (Drift)            ← استعلامات SQL مكتوبة بـ Dart
   │
   ▼
SQLite على الجهاز
```

- **الشاشة** لا تعرف شيئًا عن SQL ولا عن تجزئة الرمز السري. تعرض حالة وتنادي دوالّ.
- **المستودع** هو مكان القواعد. مثال: `ProfileRepository.verifyPin` يقرر هل الرمز صحيح وهل الملف مقفل.
- **DAO** يقرأ ويكتب فقط، بلا قواعد.
- **core/utils** دوال بلا اعتماد على Flutter (تُختبر كـ Dart صرف).

## كيف تصل البيانات للشاشة
Riverpod يربط الطبقات. مثال: `databaseProvider → profileRepositoryProvider → profilesProvider (Stream)`. حين تتغير بيانات الجدول يعيد الـ `Stream` قيمة جديدة فتُبنى الشاشة تلقائيًا بلا `setState` يدوي.
في الاختبارات نستبدل `appDatabaseProvider` بقاعدة في الذاكرة، فلا نحتاج أي استثناءات في كود التطبيق.

## التنقل
`go_router` في `app/router.dart`. القاعدة: الشاشة تنتقل بـ `context.go/push(AppRoutes.xxx)` ولا تستورد شاشة أخرى مباشرة. قرارات «إلى أين يذهب المستخدم عند فتح التطبيق؟» ستكون في `redirect` الراوتر (المرحلة 4).

## العربية والاتجاه (RTL)
- `locale: ar` في `MaterialApp` يقلب الاتجاه تلقائيًا: **أول عنصر في `Row` يظهر على اليمين**.
- نستخدم `EdgeInsetsDirectional` و`AlignmentDirectional` بدل `left/right`.
- الأرقام غربية (0–9) كما في التصميم.
- لوحة أرقام الرمز السري LTR عمدًا (1 2 3 / 4 5 6 / 7 8 9) كما في التصميم.

## الثيم والخط والنصوص
- `AppColors` قيم Figma حرفيًا. `AppTextStyles` أنماط Cairo (الاسم يحمل الحجم، مثل `heading22`).
- الخط داخل التطبيق (`assets/fonts`) ومعرَّف في `pubspec.yaml` بأوزان 400/600/700/800. لا اعتماد على الإنترنت.
- **كل نص ظاهر** يُكتب في `core/strings/ar.dart`، لا داخل الشاشات. هذا يسهّل الترجمة لاحقًا.

## قاعدة: أرقام التصميم أمثلة
أي رقم أو اسم في Figma (75%، 24 نجمة…) مثال لشكل الشاشة. الكود لا ينسخه: القيم تُحسب من قاعدة البيانات والكتالوج.

## الاختبارات
- **Unit:** `test/core/*` (رمز الطالب، تجزئة الرمز السري والقفل، حساب السلسلة).
- **مستودعات:** `test/features/*` على قاعدة Drift في الذاكرة.
- **Widget:** `test/widget_test.dart` يمرّ على مسار الشاشات. يحمّل خط Cairo الحقيقي عبر `test/helpers/load_fonts.dart`؛ بدونه يستخدم `flutter_test` خطًّا عريضًا بديلًا فتظهر أخطاء تجاوز وهمية.

## قرارات تقنية تستحق المعرفة
| القرار | السبب |
|---|---|
| `drift` 2.31 و`drift_flutter` 0.2.x و`flutter_riverpod` 2.6.1 | Flutter 3.38.3 يثبّت `meta 1.17`، وأحدث `drift_dev` و`riverpod 3` يتعارضان معه. الترقية الكاملة تتطلب ترقية Flutter. |
| ملفات `*.g.dart` داخل Git | حتى يعمل المشروع بعد النسخ دون تشغيل `build_runner`. تُولَّد بـ `dart run build_runner build`. |
| `minSdk = 24` | هو الحد الأدنى الذي يدعمه Flutter 3.38 رسميًا. |
| `google_fonts` محذوف | يجلب الخط من الإنترنت وهذا يخالف مبدأ «دون إنترنت أولًا». |
